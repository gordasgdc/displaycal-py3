## How the GitHub mark is used

* Only next to the text label "Give a star on GitHub" (an accessible name is set
  as well; the logo is never the only cue), to link to the project page.
* Unaltered: not recoloured, distorted, combined with other elements or given
  effects. The black or the white official variant is chosen for contrast with
  the current theme, and it is rendered on the plain button background.
* Smaller and less prominent than the application's own name and symbol.
* It is not used as the application's logo or icon and implies no affiliation
  with or endorsement by GitHub.

## Instrument manufacturers

X-Rite, Calibrite and Datacolor/Spyder are named in text only (nominative
reference to the instruments the measurement engine supports). Their logos are
**not** used: no published brand-use terms allowing a third-party application to
show them were found on 2026-10-19, and there is no partnership, approval or
certification with any of them. If a manufacturer publishes a brand kit that
permits this use, add the assets here with their terms before using them.
